# Contributing to Niroga

Thank you for your interest in contributing to Niroga!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/clinical-enhancement`)
3. Commit your changes (`git commit -m 'Add support for pediatric triage'`)
4. Push to the branch (`git push origin feature/clinical-enhancement`)
5. Open a Pull Request

## Coding Standards

- Keep UI code clean and modular.
- Maintain accurate medical triage criteria adhering to Sri Lankan healthcare guidelines.
- Ensure all patient data remains private and local.
